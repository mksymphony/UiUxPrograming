# Virtual Character Studio

HTML, CSS, JavaScript로 제작한 버추얼 캐릭터 소개 및 제작 신청 **시연용** 웹페이지입니다. 실제 제작 신청을 접수하거나 서버로 정보를 전송하지 않습니다.

## 주요 사용자와 목표

- **주요 사용자:** 버추얼 캐릭터 제작과 활용에 관심 있는 사용자
- **서비스 목적:** 3D 제작, 실시간 페이스 트래킹, 방송 활용 정보를 소개하고 제작 신청 과정을 체험하게 합니다.
- **핵심 행동:** 캐릭터 이름 입력 → 활용 목적 선택 및 시연 안내 확인 → 신청 내용 검토 → 확정
- **완료 조건:** 이름·활용 목적·안내 확인이 유효하고, 확정을 눌러 완료 화면에 도달합니다.

## 이전 주차 기능

- **4주차:** viewport, 유동 너비, CSS Grid 기능 카드, 768px 이하 반응형 레이아웃
- **5주차:** JavaScript 입력 확인과 submit 이벤트, 안내 문구/버튼 상태 피드백
- **6주차:** 3개 기능 탭의 click 전환, 캐릭터 이름 input 글자 수·미리보기, 선택 change 피드백

## 7주차 사용자 흐름 (5단계)

1. **시작:** `제작 신청 시작하기`를 눌러 입력 단계로 이동
2. **이름 입력:** 최대 20자의 캐릭터 이름을 입력하고 실시간 미리보기를 확인
3. **활용 목적 선택:** 방송 / VRChat / 영상 중 하나 선택, 과제 시연 안내 체크
4. **내용 확인:** 이름, 활용 목적, 안내 확인 상태를 표시; `이전 · 수정하기`로 돌아가 수정 가능
5. **완료:** `신청 확정하기`로 완료 화면 표시; `처음부터 다시 시작하기`로 상태 전체 초기화

## 인터랙션 시나리오

| 사용자 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
|---|---|---|---|---|
| 시작 버튼 누름 | click | 없음 | 이름 입력 화면 표시 | 입력 |
| 이름 입력 | input | 글자 수 0~20 | 글자 수/미리보기 갱신 | 입력 유지 |
| 이름 없이 다음 | click | `trim()` 결과 빈 문자열 | 오류 안내와 입력창 초점 | 입력 유지 |
| 이름 입력 후 다음 | click | 이름 존재 | 선택 화면 표시 | 선택 |
| 활용 목적 변경 | change | 선택 여부 | 오류 해제/버튼 준비 상태 갱신 | 선택 유지 |
| 안내 확인 체크/해제 | change | checked 참/거짓 | 안내 문구·색·버튼 상태 변경 | 선택 유지 |
| 미선택 상태에서 다음 | click | 목적 또는 안내 확인 누락 | 해당 항목 수정 안내 | 선택 유지 |
| 내용 확인 | click | 입력·선택 충족 | 입력값 및 선택값을 요약 표시 | 확인 |
| 이전 버튼 | click | 없음 | 이전 단계 이동, 값은 유지 | 선택 또는 입력 |
| 수정 후 다시 확인 | click | 조건 충족 | 변경된 값으로 요약 갱신 | 확인 |
| 신청 확정 | submit | 최종 조건 충족 | 완료 문구·버튼 상태 변경 | 완료 |
| 다시 시작 | click | 완료 상태 | 입력·선택·오류·진행 상태 초기화 | 시작 |
