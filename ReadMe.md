
# Virtual Character Studio

버추얼 캐릭터 제작과 실시간 방송 활용을 소개하는 웹페이지입니다.

## 프로젝트 소개

HTML, CSS, JavaScript를 사용하여 제작한 UI/UX 프로그래밍 과제입니다.

주요 기능:
- 3D 버추얼 캐릭터 제작 소개
- 실시간 페이스 트래킹 소개
- 방송 활용 정보 제공
- 캐릭터 제작 신청 체험

## 4주차 - 반응형 웹페이지

- viewport 메타 태그 설정
- CSS Grid를 이용한 기능 카드 배치
- 768px 이하에서 메뉴 및 카드 세로 배치
- 390px 모바일 화면 대응
- 입력창과 버튼의 반응형 배치

## 5주차 - JavaScript 기초

- 캐릭터 제작 신청 폼 구현
- submit 이벤트 처리
- 빈 입력값 검사
- 신청 결과 문구 및 스타일 변경
- 신청 완료 시 버튼 비활성화

## 6주차 - 이벤트 처리와 동적 UI

### click 이벤트

3개의 기능 탭을 클릭하여 콘텐츠를 전환합니다.

선택된 탭은 빨간색 배경으로 표시되며
해당 기능의 설명만 화면에 표시됩니다.

### input 이벤트

캐릭터 이름을 입력하면 다음 항목이 변경됩니다.

- 현재 입력한 글자 수
- 캐릭터 이름 미리보기
- 미리보기 스타일

### change 이벤트

제작 안내 확인 체크박스를 선택하면
신청 버튼이 활성화됩니다.

체크를 해제하면 버튼이 비활성화되고
안내 문구와 스타일이 변경됩니다.

### submit 이벤트

캐릭터 이름을 입력하고 신청하면
완료 문구와 버튼 상태가 변경됩니다.

실제 서버로 신청 정보를 전송하지 않는
과제용 시연 기능입니다.
