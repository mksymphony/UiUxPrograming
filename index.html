서비스 소개

Virtual Character Studio는 사용자가 원하는 버추얼 캐릭터를 제작하고 실시간 콘텐츠에서 활용할 수 있도록 도와주는 서비스입니다.

주요 기능

3D 캐릭터 제작

사용자의 요구에 맞는 3D 버추얼 캐릭터를 제작합니다.

실시간 페이스 트래킹

얼굴의 움직임과 표정을 버추얼 캐릭터에 실시간으로 적용할 수 있습니다.

실시간 방송 활용

완성된 캐릭터를 버추얼 방송과 다양한 실시간 콘텐츠에서 활용할 수 있습니다.

기능 자세히 보기

3D 캐릭터 제작

Blender를 활용해 모델링, 리깅과 표정 설정을 진행합니다.

실시간 페이스 트래킹

ARKit 기반 표정 추적을 통해 눈과 입의 움직임을 실시간으로 표현합니다.

실시간 방송 활용

완성된 캐릭터를 Warudo와 OBS 등의 프로그램에서 활용할 수 있습니다.

이용 방법

  1. 제작 신청 시작 버튼을 누릅니다.
  2. 캐릭터 이름을 입력하고 활용 목적을 선택합니다.
  3. 입력한 정보를 확인한 다음 신청을 확정합니다.
  4. 완료된 시연 신청은 '내 신청 내역'에서 다시 확인하거나 취소할 수 있습니다.
